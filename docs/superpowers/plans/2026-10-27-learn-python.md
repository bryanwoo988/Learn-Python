# Python Syntax · Python语言 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.0.0 of a bilingual (en/zh) offline Python-learning PWA with 18 chapters, ~83 graded problems, a Playground and LearnSQL-style Settings.

**Architecture:** Static site, no build step, cloned from Learn-SQL's shell. Python runs in Pyodide 314.0.7 inside a module Web Worker; one Python file (`py/runtime.py`) does running, grading, figure capture and error cleanup, and is shared by the browser worker and the Node checker. Content lives in plain JS data files per course part; code comments are bilingual through one `#:` comment convention.

**Tech Stack:** HTML/CSS/vanilla JS, Pyodide 314.0.7 (Python 3.14.2), numpy 2.4.6, pandas 3.0.2, matplotlib 3.10.8, scipy 1.18.0, scikit-learn 1.8.0; Node 22 for tools; Playwright (pre-installed) for the browser smoke test.

**Spec:** `docs/superpowers/specs/2026-10-27-learn-python-design.md`

## Global Constraints

- Storage prefix `pysyntax.`; cache prefix `py-syntax-`; core cache `py-syntax-<VERSION>`; package cache `py-syntax-pkgs-314.0.7`. The SW deletes only `py-syntax-*` caches other than those two.
- Release rule: `js/releases.js` (`window.PY_RELEASES`, en+zh) top entry == `sw.js` `VERSION`; `node tools/check-release.mjs` passes before push. First version `1.0.0`, all 18 chapters at once.
- No external network at runtime: everything under `vendor/` on GitHub Pages.
- Measured sizes (2026-10-27): core layer ≈ 13 MB (`pyodide.asm.wasm` 9.6 MB, `python_stdlib.zip` 2.5 MB, `pyodide.asm.mjs` 1.25 MB); data pack ≈ 35 MB (17 wheels; scipy 14 MB). The download prompt shows "≈ 35 MB".
- Data pack wheels = closure of numpy, pandas, matplotlib, scikit-learn, scipy in `pyodide-lock.json`.
- Code text: identifiers, `print` output, data, CSV, chart text in English; comments localised via `#:` (see Task 3). Chart text English only, no CJK font.
- All prose, examples, data and problems original; chapter order only from W3Schools.
- Do not modify `/home/user/Learn-SQL`.
- Run timeout: 10 s for chapters 1–11 and Playground without packages, 40 s when data pack is in use. Timeout counts from when the worker starts executing, not while Pyodide/packages load.
- Output cap: 2,000 lines or 100 KB of stdout per run, then stop with a bilingual "output too long" message.

## Review Focus

1. Infinite loop with or without `print` (`while True: pass`, `while True: print(1)`) → stopped at the timeout/output cap, worker restarted, page responsive, next Run works.
2. Data-pack chapter opened offline before the pack was downloaded → clear "needs a one-time ≈35 MB download, connect to the internet" message, no hang; basics still work.
3. Learner shadows builtins or pollutes state (`print = 3`, `import os; os.remove(...)`, editing a CSV) → next run starts from a fresh namespace and freshly reset files.
4. Language switch with an untouched starter vs an edited draft → untouched starter follows the language, edited draft is kept verbatim.
5. Float/ordering noise (`0.1+0.2`, dict order, DataFrame index after filtering, trailing whitespace) → graded as correct when the values match within 1e-6 and order doesn't matter unless the problem says so.

Each item has a test in the owning task (Tasks 2, 5, 4, 3, 2 respectively).

### Task 2: Python runtime and worker

**Files:**
- Create: `py/runtime.py`, `js/py-worker.js`, `js/engine.js`, `tools/test-runtime.mjs`, `tools/node-py.mjs`

**Interfaces:**
- `py/runtime.py`:
  - `run(code: str, setup: str = '', files: dict[str,str] = {}, stdin: list[str] = []) -> dict` → `{ stdout, error: None | {type, msg, line}, images: [png_base64], ns_keys }`. Fresh `__main__`-like namespace each call; resets `/home/pyodide/work` from `files` and `chdir`s there; `plt.close('all')` before and figure capture after; warnings filtered; stdout capped (Global Constraints) raising `OutputLimit`.
  - `grade(code: str, solution: str, check: dict, setup: str, cases: list[dict], files: dict) -> dict` → `{ ok: bool, case: int, hidden: bool, reason: str, got: str, exp: str, stdout, images, error }`. `reason` is a key the JS side translates (`stdout`, `return`, `value`, `figure`, `assert`, `missing`, `error`).
  - `check` shapes: `{type:'stdout'}`; `{type:'function', name, calls:[[args...]]}`; `{type:'values', exprs:[str]}`; `{type:'figure'}`; plus optional `asserts:[str]` (each must be truthy in the learner namespace) and `ordered:bool` (default false for DataFrames/sets, true for lists/stdout).
  - `same(a, b, ordered) -> bool`: numbers within 1e-6 (rel or abs), recursive containers, numpy arrays, DataFrame/Series (reset index unless `ordered`; compare columns, values, dtypes kind), stdout compared after stripping trailing spaces per line and trailing blank lines.
  - `figure_summary() -> list` per axes: `{kind_counts, title, xlabel, ylabel, lines:[ydata], bars:[heights], points:[offsets], hist}`.
  - Tracebacks keep only frames from `<learner>`; `line` is the learner's line number.
- `js/py-worker.js` (module worker): messages in `{id, op:'init'|'load'|'run'|'grade', ...}`; out `{id, op:'started'}` when execution begins, `{id, op:'done', result}`, `{id, op:'fail', message}`.
- `js/engine.js` → `window.PyEngine = { ready(): Promise, run(opts): Promise<result>, grade(opts): Promise<result>, stop(), usePackages(): Promise, packState(): Promise<'none'|'partial'|'ready'>, downloadPack(onProgress(bytes,total)): Promise }`. Timeout or `stop()` → `worker.terminate()`, new worker, resolve `{ error:{type:'Timeout'|'Stopped'} }`.

- [ ] Step 1: `tools/test-runtime.mjs` (Node, loads `vendor/pyodide` + `py/runtime.py` via `tools/node-py.mjs`) with assertions:
  - `run('print(1+1)').stdout === '2\n'`
  - `run('print(x)').error.type === 'NameError' && .line === 1`
  - `run('for i in range(10**6): print(i)').error.type === 'OutputLimit'`
  - `run('print = 3')` then `run('print("ok")').stdout === 'ok\n'`
  - `run('open("a.txt","w").write("z")', '', {'a.txt':'y'})` then `run('print(open("a.txt").read())', '', {'a.txt':'y'}).stdout === 'y\n'`
  - `run('print(input()+input())','',{},['a','b']).stdout === 'ab\n'`
  - grade stdout: learner `print(0.1+0.2)` vs solution `print(0.30000000000000004)` ok; `"a  \n\n"` vs `"a"` ok
  - grade function with hidden call failing → `{ok:false, hidden:true}`
  - grade values: DataFrame filtered (index 1,3) vs reset index → ok when `ordered` false
  - grade figure: bar heights differ → `{ok:false, reason:'figure'}`
- [ ] Step 2: Run → fails (no runtime). Step 3: implement `py/runtime.py`, `tools/node-py.mjs`. Step 4: run → all pass.
